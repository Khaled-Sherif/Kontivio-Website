# Kontivio v3 — Drop-in Replacement (No Manual CSS Editing)

This folder contains **complete files** to replace your existing ones. No appending, no manual editing.

## What to do

### 1. Replace `kontivio.css`
Drag `kontivio.css` from this folder into:
```
D:\New folder\Kontivio\my-app\src\styles\
```
Replace the existing file.

### 2. Replace component files
Drag all files from `components/` folder into:
```
D:\New folder\Kontivio\my-app\src\components\
```
Replace existing files when prompted.

Files included:
- `Header.tsx` (replaces — has mega-menus + Careers removed from About)
- `Industries.tsx` (replaces — gradient fallbacks per card)
- `CustomerSupportSolutions.tsx` (NEW page)
- `TechnologySolutionsPage.tsx` (NEW page)
- `BusinessDevelopmentPage.tsx` (NEW page)
- `TechnologyPartnersPage.tsx` (NEW page)
- `OurStoryPage.tsx` (NEW page)
- `BoardOfDirectorsPage.tsx` (NEW page)

### 3. Replace `App.tsx`
Drag `App.tsx` from this folder into:
```
D:\New folder\Kontivio\my-app\src\
```
Replace the existing file.

### 4. Hard refresh your browser
`Ctrl+Shift+R`

## That's it

No CSS appending. No file merging. Just drag-and-drop replace.
